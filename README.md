# Дела того дня — русский интерфейс

**Оригинальное расширение: [andnluv/onthatday](https://github.com/andnluv/onthatday). Автор оригинала — [andnluv](https://github.com/andnluv).**

Вклад этого форка от [huareyu](https://github.com/huareyu) — только перевод интерфейса на русский: вкладок, кнопок, настроек, подсказок, уведомлений и справочных подписей. Само расширение и его функции разработаны автором оригинала.

**Промпты оставлены на английском языке.** В инструкциях для модели указан русский язык отображаемых подписей и описаний.

## Что это

Расширение для SillyTavern, которое отслеживает вымышленные ABO-параметры персонажа и персоны пользователя: самочувствие, феромоны, циклы, связи, предпочтения, сцены, беременность и сюжетное время. Данные сохраняются отдельно для каждого чата.

## Установка

1. Откройте раздел расширений SillyTavern и выберите установку расширения по ссылке.
2. Вставьте адрес этого репозитория:

   ```text
   https://github.com/huareyu/onthatday
   ```

3. Обновите страницу SillyTavern.
4. В меню расширений (волшебная палочка) откройте **«Дела того дня»**.

Если у вас уже установлена другая копия onthatday, отключите её перед использованием этой версии, чтобы две копии не работали одновременно. Перед заменой сохраните резервную копию данных расширения.

## Начало работы

1. Откройте чат и проверьте выбранных персонажа CHAR и персону USER.
2. На вкладке «Профиль» запустите начальный анализ, проверьте предложения и примените нужные.
3. На вкладке «Настройки» выберите подключение модели для анализа.
4. Для старых подписей на другом языке используйте перевод существующих записей или перевод подписей предпочтений.

Анализ и перевод через ИИ могут выполнять дополнительные запросы к API. Проверяйте результаты перед применением. Расчёты препаратов, циклов и беременности — вымышленные игровые механики оригинального расширения.
